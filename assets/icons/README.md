# Social brand icons

These SVGs are vendored from [Simple Icons](https://simpleicons.org/) and are distributed under
CC0-1.0. The repository already includes `LICENSES/CC0-1.0.md`.

`github.svg`, `googlescholar.svg`, and `orcid.svg` use the current Simple Icons paths. `twitter.svg`
uses the archived Simple Icons Twitter bird so the site preserves its original visual identity;
current Simple Icons releases use the X mark instead. The SVG fills are set to white for the site's
sidebar presentation.
